1. 策略定位：动态半中性

正式定名 「动态半中性策略」。与两类做法对比：

类型做法收益/风险
纯多头量化只买股票不对冲大盘回落时"选再好的股票也拗不过大趋势"，2026年6–7月回撤有到30%+
真·市场中性常年满仓股票 + 等量股指空单按权重锁死一直正收益但低，年化六七个点，达不到要求
本策略：动态半中性只在关键顶/底用股指出手；不按权重、只按总金额做相关性对冲；保留方向性获利顶锁利+反手吃跌、底反手吃涨；力争85%胜率、绝不深度回撤
"半"的工程含义：对冲不逐一匹配指数权重（那是真中性），而是按总金额近似对冲——"我只管的是钱"。锁的是一个总敞口金额，不与个股权重一一对应。股票与股指无强制方向绑定：大盘跌而这 300 只还涨，是最好结果（股指赚 + 股票赚，"两份钱"）。
⚠ 独立风险提示（须并列告知资金方）：在 32% 保证金档，配约 10 倍杠杆后是 净方向头寸（净空/净多名义 ≈ 总资金的 3 倍量级），赌对赚约 40%、赌错即深度回撤。"绝不回撤"实质依赖 顶/底判断的高胜率 + 硬止损 + 错向保护单；一旦系统性看错叠加跳空，纸面保护可能失效。此为策略最需诚实披露之处。

2. 五个市场形态（模式）总览

核心假设：A股基本在以下 五个形态 之间来回转换，每个形态对应一套固定动作与资金边界。识别当前形态 → 执行对应模式，是整个系统的骨架。

模式形态股指动作股票动作
模式一阶段顶部开空对冲/反手停止新开，转跌即卖
模式二阶段底部开多同步启动建仓
模式三中途盘整轻量试探，不打满≤80% 分批，不极端集中
模式一-1顶部下探反抽成双头后再下行二次开空（≤32%）双头后期平空、资金回流股票
模式二-1底部反弹回踩成双底后再上行二次开多（≤32%）双底后期平多、股票向80%加仓

另有两种不常发生的形态（已由预设规则覆盖）：① 顶部下行→盘整→向上突破前高再上行；② 底部反弹回踩→突破前低再下行。因预设"盘整时股票多仓 ≤80%、突破前高时股票已有盈利再找位开空锁利；回踩时股指开空，若跌破前低则继续持空保持盈利，直至再找位平空开多即可"，故无需单列。

3. 资金分配约束模型（核心公式）

总资金 T（不含浮盈浮亏） 股票侧 S ∈ [20%, 80%] · T 股指侧 Z ∈ [20%, 80%] · T S + Z = T Z 均分两账户：A本金 = B本金 = Z ÷ 2 单账户开仓保证金 ≤ 该账户本金 × 80% （账户内至少留 20% 现金做缓冲） A+B 合计开仓保证金 ≤ Z × 40% ← 硬顶 ⇒ 股指保证金占总资金 = (Z/T) × 40% Z=20%·T 时 → 8% （顶部初锁档，近似中性） Z=80%·T 时 → 32% （重仓方向档，硬顶，信号再强不破）
关键洞察：坊间说的"8% → 32%"不是两个魔法数字，而是 股指侧资金 Z 从占总资金 20% 提升到 80%，再 ×40% 保证金率 的自然结果。开发时把 8%/32% 实现为 Z×40% 这一个约束即可，Z 随模式在 [20%,80%] 间移动。

各模式的硬性底线（比例口径不含浮盈浮亏）：

模式股票侧股指侧 Z特有底线
一·顶部达 80% 上限时留存 ≥20%股指保证金上限随 Z 增长到 32%
二·底部现金+持仓 ≥20%可至 80%股指保证金 32% 上限
三·盘整≥20%（且 ≤80%）≥20%（且 ≤80%）禁止资金极端集中至单一账户；仅轻量试探不打满

4. 股指组合与双账户错向保护

4.1 正式稿的 A/B 双账户设计

  • A = 主交易账户：到预设技术指标点位执行开空（顶部）/开多（底部）。
  • B = 错向风险保护账户：不在主信号点位开仓；在 A 开空点位的上方（底部则下方）预设价位，挂对等数量的反向预备单。
  • 若 A 方向看错，行情反向触发 B 的预设单 → B 成交对等反向仓 → 跨账户对锁，把亏损约束在预设可承受区间，阻止扩大。
  • 若 A 方向正确，B 不触发，保持现金待命。
  • 阈值触发：A 方向正确且 A+B 合计保证金达 Z×40%（=总资金 8%）时，该期货敞口用于对冲股票组合（股票占总资金 ≤80%）。
⚠ 与录音的口径需调和（务必确认）：正式稿保留 A/B 两个物理账户做错向对锁；但操盘手在录音里说"境内交易所支持双向持仓且保证金可共用，其实一个账户就够，双账户是我做港股（单向持仓）时的遗留"。
建议实现口径：境内用"单账户双向持仓 + 预设反向保护挂单"即可实现同等错向保护，功能上等价于 A/B 设计，且省去跨账户通算的依赖（见 12.1）。是否物理分两户，取决于期货公司多账户保证金通算许可与保证金效率——请与期货公司确认后定稿。

4.2 股指标的与额度

  • 交易标的：沪深300(IF)、中证500(IC)、中证1000(IM)，理论开仓额度各占 1/3。
  • IC、IM 相对 IF 存在基于历史回测的偏差系数；三个指数各按自身预设技术指标独立判断开仓信号，不强制同时触发（谁到位谁先开，另一个等着）。
  • 不用上证50（波动太小，对冲价值低）。

5. β / 偏差系数测算

锚定：沪深300 β = 1 中证500 β ≈ 1.4 中证1000 / 2000：按行情各自独立测算 个股 β：个股日收益 = α + β·股指日收益 + ε （60日或多窗口滚动回归）
  • 用途：把股票组合与股指对齐，算"对冲 80% 股票需几手股指"，反推验证"8% 保证金 ≈ 锁 80% 市值"。
  • 上下行不对称：分上涨日/下跌日子样本估 β（要的正是"跌时小盘跌更多、涨时涨更多"的高弹性）。
  • 稳定性打分（β 均值/波动/R²）；β 飘忽者剔除。风格切换后系数会漂移，须定期重估（见 12）。

6. 选股模块（1200→300 + 因子强弱分档）

6.1 基础池（约1200只）

  • 全市场约 3800 → 初选 1200。剔除 ST；剔除年化日均成交量 < 总股本 1% 的（流动性不足）。
  • 动态复核：每日/定期，达标纳入、不达标剔除。

6.2 交易池（固定持仓约300只）· 相对强弱排序

  • 由股指组合方向驱动排序，不自研基本面：股指涨 1% 时，按"谁涨得更多"排（涨10%排在涨1%前）；股指跌时，按"谁跌得更少/仍在涨"排。
  • 连续打分/重排（今天快、明天可能转弱即换位）。数量级：500 里选约 50、2000 里选约 150，合计约 300。
  • 操盘手简化原则：沪深300/500 等指数已用更多因子筛过一次，我们只做成分股内的相对强弱二次排序。

6.3 因子强弱分档（本次新增定义 · 回测标定用）

用户给定的因子权重口径：
因子档内容作用
强 / 次强技术指标 + 成交量选股与打分的主因子，决定"优/次优"排序
中 / 次弱 / 弱其他因子（基本面、政策/新闻/个股利空利好等）辅助/正向助推，不作独立否决、不做加分项（消息面不可控，仅正向时可关注）
这与整体哲学一致：技术+量价为主引擎，其他因子只做正向助推、不当家、不否决。开发时，"其他因子"的贡献应实现为受上限约束的置信度加权（例如仅微调仓位系数），不得突破技术+量价主信号定下的仓位框架，也不得独立触发开/平仓。

6.4 资金分配：市值5档 × 强弱系数

先按流通市值分 5 档做均衡分配（防钱堆到少数小盘、涨上去卖不掉），再按相对强弱给系数——强者多给，不按市值权重给。

市值档（示例）强弱系数
① <50亿最强×1.5
② 50–100亿次强×1.25
③ 100–200亿中位（基准≈20%/档）×1.0
④ 200–500亿次弱×0.75
⑤ >500亿最弱×0.5

用户将进一步细化"入选股票分档"的界定；本表为现口径，待其定稿后回测标定。

7. 五模式详解 + 情景测算（初始总资金 5000万，不含浮盈浮亏）

模式一 · 阶段顶部（股指开空对冲）

初期：股票 4000万(80%) ; 股指 Z=1000万(20%)，A=500 / B=500 单账户最大保证金 200万；A+B合计上限 400万 = 总资金8%（触发阈值） 触发后：卖出转跌个股 → 停止新开股票 → 回笼资金转入股指 边界：股指 Z=4000万(80%)，A=2000 / B=2000；合计保证金上限 1600万 = 总资金32% 股票侧(现金+上涨持仓)=1000万(20%)，停止资金调拨

性质初期 8% ≈ 中性锁利；随下跌确认，Z 提升、保证金向 32% 走 → 转为净做空反手吃跌。

模式一-1 · 双头（顶部下探反抽成双头后再下行）

  • 初始 A 可用 500万，用 80% 即 400万开空 = 总资金 8%。
  • 股票卖出资金转入股指，A 可用本金提升，二次开空上限 ≤ 总资金 32%（1600万保证金）。
  • 双头后期：平掉 IF/IC/IM 获利空单 → 资金回流股票端 → 股票逐步向 80% 上限建仓 → 自动转模式三。

模式二 · 阶段底部（股指开多）

边界：股票底线 ≥1000万(20%)；股指 Z=4000万(80%)，A=2000 / B=2000 合计保证金上限 1600万 = 总资金32% 执行：A 按各指数信号开多；B 挂下方对等空仓保护；股票同步启动建仓

模式二-1 · 双底（底部反弹回踩成双底后再上行）

  • 初始 A 可用 2000万，用 80% 即 1600万开多 = 总资金 32%。
  • 股票建仓完成后，资金在 IF/IC/IM 之间动态调配；二次开多上限 ≤ 总资金 32%。
  • 双底后期：平掉获利多单 → 资金回流股票 → 股票向 80% 加仓 → 自动转模式三。

模式三 · 中途盘整

  • 股票侧(现金+持仓) ≥20%；股指侧 ≥20%（且各 ≤80%）；禁止极端集中至单一账户。
  • 股指仅轻量试探，不打满保证金上限；股票分批加仓，不直接打满 80%。
  • 顶部下行进盘整：转跌个股择机卖出、少量择优选股；底部上行进盘整：试探性开仓、股票分批。
净敞口速算（占总资金）：8% 保证金 ×10 ≈ 名义 80%（对冲 80% 股票，近似中性）；32% 保证金 ×10 ≈ 名义 320%，此时股票已降到 20%，净方向 ≈ ±300%。→ 32% 档是重杠杆方向头寸，风控须与 8% 档完全分离。

8. 模式切换规则

  1. 盘整区间向上有效突破 → 走向阶段顶部：模式三 → 模式一，完整执行模式一规则。
  2. 盘整区间向下有效跌破 → 走向阶段底部：模式三 → 模式二，完整执行模式二规则。
  3. 未有效突破/跌破盘整边界：持续模式三，禁止提前执行模式一/二的极限资金调拨。
  4. 模式一-1（双头）走完平仓后，自动转入模式三。
  5. 模式二-1（双底）走完平仓后，自动转入模式三。

"有效突破/跌破"的量价判据（涨跌幅、成交量、短周期指标）须回测标定；防假突破。

9. 开仓 / 卖股 / 止损信号

9.1 分批锁仓

出圈（破布林上轨约 2%）后不一笔锁死，分 4 回逐步锁到 8%；强票可多等一点多赚再锁。

9.2 卖股（"不涨就卖"）

  • 顶部确认后，与大盘同步掉头的股 → 一掉头就卖（不等暴跌）。
  • 判据："今天涨不动；明天只要比今天低 2% 就卖，只要不创新高就卖。"
  • 手写批注（风险条款 7.4）：个股在任一模式中弱于股指组合达约 −2%（相对）即平掉，无论对错。
  • 留下的是逆势上蹿下跳的小盘活跃股 → 提供"两份钱"里的超额。

9.3 止损（"随时准备做错"）

纪律：高位开 8% 空后若价格被硬拧上去 2%，平掉——损失 = 8%×2% = 总资金 0.16%（会上确认过：不是 1.6%，是 0.16%），极小。之后指标掉头（KDJ 下穿、5日线拐头下穿）再顺势做，博下方 5–十几个点。错向保护单（B/预设反向单）是兜底。

10. 升水 / 贴水利用

基差=期货−现货，结算日收敛（约 6 点内）。操盘手动作方向让基差长期站在自己一边（对应其手写批注）：

时机基差动作效果
上升期/顶部升水（期货虚高，港股经验曾高两三百点）顶部开空在虚高处开空，结算回落=捡红包
下行期贴水（期货领先下跌）持有空仓持空更赚（"也相当于捡红包"）
超低位贴水放大（"一根针"）平空、开多方向正确又是捡红包，反手做多好时点
会上澄清：开空的触发是"股指出圈"，不是"股票下跌"；且只在顶部开空、底部开多，方向固定，所以升贴水始终有利。

12. 通用风险约束条款

  1. 7.1 跨账户对锁与多账户通算，必须取得期货公司业务许可；若无法落地，错向保护机制失效，需修订整体风控。（→ 若改用单账户双向持仓可规避，见 4.1）
  2. 7.2 股票批量买卖必须评估标的流动性，防范大额滑点冲击成本。
  3. 7.3 股指期货存在升贴水、移仓损耗，持续侵蚀净值。（手写：升水多在上升期，此时开空相当于捡红包；贴水多在下行期，此时持空也相当于捡红包；超低位平空开多、方向正确又相当于捡红包）
  4. 7.4 本策略属动态半中性，仅对冲大盘系统性风险，无法对冲个股黑天鹅，个股仍需独立止损。（手写：个股在任一模式中弱于股指组合约 −2% 即平掉，无论对错）
  5. 7.5 期货极端跳空会使预设保护点位无法成交，保护机制失效。（手写：日内无大风险；隔日若在顶部则无风险，若在底部则冗余资金足以应对）
  6. 7.6 双头/双底是事后确认形态，盘中易出假反抽/假回踩，造成来回开平损耗，须严格确认量价条件再切换。（手写：量度够时有足够空间，只是盈少盈多之别）
⚠ 整理方补充（供并列告知资金方）：① "绝不回撤"与 32% 档净方向头寸存在张力，非零风险；② −17、乖离 20% 等阈值源自港指手感，须用A股重标；③ 85% 胜率是目标非已证，回测须含 2015/2018/2024–25 极端段与滑点、移仓、手续费；④ 关键人风险：核心判断仍依赖操盘手手感，规则化是机构化前提；⑤ 对外"做股票"话术与"利润主来自股指期货"实质须如实披露。
